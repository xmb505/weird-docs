# 三一工学院校园网绕过文档

> 2026 年，要毕业了，把知道的都留下。

## 背景

2026 年初学校换了运营商，引入了 DPI，还有人工上门查。
资本比以前难搞多了，他们的第一要务就是赚钱，多设备上网的需求直接爆炸。

## 26 年之前的历史存档

当时 AP 网线：

- **VLAN ID 2000**：校园网千兆链路
- **VLAN ID 2001**：免费网络，直接飞起，千兆下载 / 百兆上传

## 26 年之后

### 网络隔离

- 每一栋楼之间被隔离了。
- IP 跟着 MAC 走：表面上来看你去另一栋 IP 没变，但是你无法和原来那一栋的设备通信了，就算看起来同网段也一样。
- 楼栋 VLAN 规律：1 栋 101，2 栋 102，按规律到 10 栋 110；学校没有 4 栋，就没有 104。
- 交换机汇入点的地方有一个 VLAN 111 还是 112（忘了），这个 VLAN 可以免费上校园网，但是会招来运维，然后被按头。
- AP 似乎也接入了控制系统，AP 掉线也会招来运维。

### 硬件思路（未实测）

买一个 POE 交换机，千兆的，AP 拔掉，插上交换机；交换机从 POE 取电给自己供电，然后给 AP 供电；你走分出来的口子，VLAN ID 为自己楼栋。

可能招来运维，这个没有实测。

### 拨号系统

```
学生 --> DPI 代拨 --> 运营商 PPPoE 拨号
```

所以现在最大的问题就是：如何绕过 DPI。

### 绕过方案：小猫咪（实测）

- 配置一台 Windows 电脑去连接校园网，然后这台电脑**不提供 NAT**，而是安装上小猫咪（Clash），给局域网提供 socks5 代理，也就是 Clash 的「允许局域网连接」。
- **没有 NAT = 难以检测。**
- 实测：111 bt / 112 pcdn / 113 pcdn / 121 游戏 steam 更新 / 70 windows 看世界，没炸，局域网 socks5。
- 几台电脑一起跑没啥问题，不建议带上手机。
- 但是就算是 Clash，总感觉还是难逃 DPI 魔爪，所以建议不要登录国内很常用的软件；但是游戏我感觉可以，QQ、微信这类特征特别明显的就别开了。
- 建议在 Windows 上跑一个 PCDN 来迷惑 DPI：DPI 不会干掉 PCDN，但是人工看到超大上传会不给你的 MAC 地址分配 IP，随机 MAC 一键绕过。
- 查房的时候一定要把任何软路由、路由器全部藏起来。

## 其他发现（未继续深挖）

校园网里面有个很大的漏洞，爆了！直接 1day！

- 有一个 AC 控制服务器的 `debug=false`
- 校园网登录界面有个文件上传通道，可以一直上传文件
- 然后就没找到了
